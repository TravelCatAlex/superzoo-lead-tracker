================================================================================
API ENDPOINTS
================================================================================

GET /api/leads
  - Fetch all leads from BigQuery
  - Response: { leads: { "Company Name": { name, contacts, status, notes, ... } } }

POST /api/leads
  - Create new lead
  - Body: { company_name, contacts, status, notes, is_existing }

PUT /api/leads
  - Update existing lead
  - Body: { company_name, status, notes, ... }

DELETE /api/leads
  - Delete lead
  - Body: { company_name }

================================================================================
TROUBLESHOOTING
================================================================================

❌ API returns 500 error
   → Check Vercel function logs (Deployments → Function Logs)
   → Verify 4 environment variables are set
   → Check BigQuery table exists
   → Verify service account has BigQuery Data Editor role

❌ Dashboard loads but no leads appear
   → BigQuery table might be empty (normal on first deploy)
   → Check Network tab for /api/leads response
   → Run curl https://superzoo-lead-tracker.vercel.app/api/leads to test API

❌ Can't push to GitHub
   → git remote -v (check URL is correct)
   → git pull origin main --rebase (sync first)
   → git push origin main
